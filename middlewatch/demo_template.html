How it works. Five deterministic detectors read the daily snapshot and emit findings with field-level evidence: routing change, vessel swap, dwell, ETA drift, and transit time against the routing guide. Correlated signals on the same container are grouped into one incident so a vessel swap that moved the ETA is one alert, not three. A Claude agentic loop orchestrates those detectors as tools, verifies the containers it intends to escalate, and writes the triage. Every threshold lives in a config file — false-positive control is a feature, not an afterthought.

About this data. Everything on this page is generated by the synthetic data generator in the repository — fictional container numbers, vessels, accounts and lanes, with exceptions deliberately injected and a ground-truth file so detection quality can be measured. No carrier, customer or operational data of any kind is used.
